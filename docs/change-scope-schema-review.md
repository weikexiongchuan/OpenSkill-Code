# 变更范围与改表方案审核

来源：2026-10-07 用户要求，子代理必须检查是否扩大任务范围，改表必须确认方案是否妥当。

## 审核输入与范围判断

- 主代理派发时提供用户原始目标、已确认方案、后续限制、实际授权和明确未授权项，并逐项对应最新改动；不能只提供自己归纳的“本次范围”。
- 子代理先独立核对“用户要求 → 实现步骤 → 实际改动”，检查新增功能、业务口径、存储、表结构/索引、配置、运行依赖和生产操作是否有需求依据。
- 为实现已确认目标所必需的常规技术细节不需逐项重确认；出现实质扩大范围或新增风险时，必须指出具体变化、必要性、替代方案和影响。不能因为“更完善”“审核建议”或测试通过就视为用户授权。
- 未获确认的范围扩大属于交付阻断，与代码缺陷严重度分别记录。审核者不得自行扩大任务修复；主代理撤回越界改动或先取得用户对具体方案的确认，再实施并复核。
- 用户新增限制后，旧审核结论不能继续用于交付；按新约束重新判断当前实现，注明原测试仅证明哪个版本的技术行为。

## 业务必要性前置

- 先从用户业务语义独立判断需要解决什么，再判断实现是否正确；主代理设计中出现的机制不自动成为用户需求。
- 迁移、发包中断、重启继续未成功任务，优先复用已有字段、状态及模块。新增表/列、租约、持久重试预算或补偿流程，须说明现有能力为何不足并比较更小替代；不能以“防丢失”“更可靠”代替需求依据。
- 已有统一外部调用/模型网关时，职责不变的业务迁移不复制供应商客户端、密钥配置或物理调用指标。正常分析错误先明确暴露和定位，不用额外状态机制或无限重试掩盖问题；错误后的业务处理仍以用户明确口径为准。
- 必要性结论必须进入审核派发提示词和输出。测试通过、故障测试充分、避开大表，均不能证明未经要求的机制有必要；本次失败的业务口径不能推广为所有项目的固定规则。

## 表结构与索引变更：先审核方案

在编写依赖新结构的正式业务代码之前，形成可审核的方案，并由独立子代理确认方案妥当性。实施中才发现需要改表时，先回到方案审核，不能先制造新字段依赖，再将改表作为用户必须接受的发布前提。

方案必须回答：

1. **必要性与范围**：变更解决哪项已确认业务问题？每个字段/索引由谁写、谁读、为何必须持久化？能否复用现有结构或避免改动大表？替代方案须比较正确性、复杂度和运行成本，不能把成本转移到另一个未经确认的存储方案。
2. **真实规模**：目标库表、数据库版本、现有结构/索引、行数和数据/索引体积、增长与保留周期、读写负载；标明证据来源与未知项。生产查询仍遵守索引和权限约束。
3. **执行影响**：对具体变更评估数据库实际支持的DDL算法、是否重建/复制表、元数据锁及长事务、额外空间、日志/复制影响、业务阻塞与执行窗口；未确认的信息不能按低风险处理。
4. **兼容与恢复**：新旧应用读写、旧数据语义、是否回填及成本、发布先后顺序、失败中止和应用回滚/数据恢复。不能用可空字段、旧应用能启动或小型空闲测试库执行快代替大表迁移评估。
5. **验证与授权**：逐项记录方案审核、静态检查、隔离验证、生产规模/负载适用性、用户方案确认及生产执行授权，不能合并成一个“通过”。SQL实测按 [SQL性能验收](sql-performance-validation.md) 执行；未验证项明确列出。

用户已明确禁止改表或本次方案超出已确认范围时，不得实施依赖该变更的正式业务代码。已有明确确认可沿用，不因常规提交或补充测试重复询问。生产DDL/DML仍须在执行前列明准确目标库表、完整操作和影响范围，取得该次明确同意；开发、修复、部署、子代理审核通过均不能代替该授权。

## 派发与输出要求

子代理任务中必须包含以下要求；占位项填写本次实际事实：

> 用户目标及原话：{目标与限制}；已确认方案及授权：{依据}；未授权项：{边界}。
> 先审业务必要性，再审代码正确性。主代理计划中的机制不自动等于用户需求；优先复用已有字段、状态和统一模块。新增表/列、租约、持久重试预算或补偿流程，须证明更小替代不能满足用户实际语义；正常错误须暴露、诊断，不能用额外机制或无限重试掩盖。测试通过不能证明改动有必要。
> 对照最新设计和diff独立检查是否扩大范围，逐项说明需求依据；发现未获确认的范围扩大，单独列为交付阻断，不能因代码/测试正确而判定整体通过。
> 涉及表结构或索引时，按变更范围与改表方案审核规范独立评估必要性、免改表替代方案、真实表规模、执行影响、兼容与恢复；缺证据写未确认。当前阶段为{方案审核/实现复核}，只读，不改代码、不执行生产操作。

审核输出分别列出：范围符合性、改表方案妥当性（或不适用）、性能、稳定性、现有功能影响及启动验收（按阶段适用）。注明依据、未验项和阻断；“技术验证通过”不能覆盖“范围越界”或“改表方案未确认”。主代理将结论与当前发布资格同步到实现记录。
